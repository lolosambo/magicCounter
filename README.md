# Magic Counter

Application Django pour la gestion et le suivi de cartes Magic: The Gathering.

## Démarrage rapide

Pour déployer ce projet en local, consultez le [Guide de Déploiement Local](DEPLOIEMENT_LOCAL.md).

## Fonctionnalités

- Gestion des cartes Magic
- Système d'authentification personnalisé
- Interface d'administration
- Fichiers statiques et média

## Technologies

- Django 4.0.6
- Python 3.8+
- SQLite
- BeautifulSoup4
